# MediTeach Hospital Website

College mini project built with HTML, CSS and Python Flask.

## Structure

MediTeach_Hospital/
├── app.py
├── requirements.txt
├── README.md
├── templates/
│   ├── index.html
│   ├── about.html
│   ├── doctors.html
│   ├── services.html
│   ├── appointment.html
│   └── contact.html
└── static/
    └── css/
        └── style.css

## Run

Open the project folder in VS Code.

In the terminal:

pip install -r requirements.txt

Then:

python app.py

Open:

http://127.0.0.1:5000/

No database and no JavaScript are required.
